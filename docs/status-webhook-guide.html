Status webhook guide

Each time one of your parcels changes status, NovaX sends a signed message to an address on your server. This guide covers what we send, how to check it is from us, what happens if your server is down, and how to test before your first real order.

1Register your address

PUT /webhook
// you send
{
  "url": "https://yourshop.com/novax"
}
// we answer: 200
{ "ok": true, "delivery": "active",
  "webhook": "https://yourshop.com/novax",
  "signing_secret": "…" }

The answer contains your signing secret. Keep it on your server only.

  • The address must be public https on port 443. IP addresses and private or local hosts are refused with 422 invalid_webhook_url.
  • Calling it again returns the same secret. Add "rotate_secret": true to get a new one.
  • Send "url": "" to switch delivery off.

2What we send

4Check the message is from NovaX

We sign every message with your signing secret. On your side:

  1. Take the raw request body exactly as received. Do not decode and re-encode it first.
  2. Compute HMAC-SHA256 of <X-NovaX-Timestamp>.<raw body> using the secret, as lowercase hex.
  3. Compare sha256=<your result> with X-NovaX-Signature using a constant-time comparison.
  4. Refuse it if the timestamp is more than 5 minutes old.
// PHP (WordPress / WooCommerce)
$secret    = 'your signing secret';
$body      = file_get_contents('php://input');            // raw body, untouched
$timestamp = $_SERVER['HTTP_X_NOVAX_TIMESTAMP'] ?? '';
$signature = $_SERVER['HTTP_X_NOVAX_SIGNATURE'] ?? '';
$expected  = 'sha256=' . hash_hmac('sha256', $timestamp . '.' . $body, $secret);

if (abs(time() - (int) $timestamp) > 300 || !hash_equals($expected, $signature)) {
    http_response_code(401);
    exit;
}
http_response_code(200);                                  // answer first
$event = json_decode($body, true);                        // then do your own work
// Node.js
const crypto = require("crypto");
function isFromNovaX(rawBody, headers, secret) {
  const ts  = headers["x-novax-timestamp"];
  const sig = headers["x-novax-signature"] || "";
  const mac = crypto.createHmac("sha256", secret).update(ts + "." + rawBody).digest("hex");
  const expected = "sha256=" + mac;
  const fresh = Math.abs(Date.now() / 1000 - Number(ts)) <= 300;
  return fresh && sig.length === expected.length &&
         crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected));
}

5Answering, and what happens if your server is down

  • Answer with any 2xx within 10 seconds. Reply first and do your own processing afterwards.
  • Anything else counts as a failure: another status code, a redirect (we do not follow them), or no answer in 10 seconds.
  • We retry a failed event five more times: about 1 minute, 5 minutes, 30 minutes, 2 hours and 6 hours after each failure. That is 6 attempts over roughly 9 hours. After that we stop for that event.
  • Every retry carries the same X-NovaX-Delivery id. Store the ids you have handled and ignore a repeat.
  • Events can occasionally arrive twice or out of order. Use occurred_at to decide which is newer.
  • If you ever miss events, GET /orders/{awb} returns the current status and the full history.

6Test before your first real order

Step 1. Register your address with PUT /webhook (section 1).

Step 2. Ask us to send test events to it:

POST /webhook/test
// one status
{ "status": "Delivered" }

// or no body at all:
// one event for each of the 18 statuses
// answer: 202
{
  "ok": true,
  "queued": 1,
  "awb": "TEST-1A2B3C4D",
  "statuses": ["Delivered"]
}
  • Test events arrive within about a minute, with the same headers, signature and retries as real ones.
  • They are marked "test": true, their tracking number starts with TEST-, and tracking_url is null. No real parcel ever has a TEST- number.
  • Up to 100 test events an hour. Several sent together can arrive in any order.
  • Errors: 409 no_webhook_url (register first), 422 unknown_status (the answer lists the valid values), 429 test_limit.

Step 3. Try a booking without creating a parcel: send your normal POST /orders with "test": true added. It runs every check, returns the price and a TEST- number, creates nothing and sends no webhook.

Step 4. Your first real booking sends New booked to your address within a minute.
