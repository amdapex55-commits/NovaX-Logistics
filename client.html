Not arriving? Check this troubleshooting list
  • Event must be Order creation
  • Format must be JSON
  • URL must match the NovaX webhook URL exactly (no extra spaces/characters)
  • Signing secret must be copied exactly from Shopify (no missing characters)
  • JWT verification must be OFF on the Supabase Edge Function (Shopify does not send a Supabase auth token)
Import orders you already haveoptional

New orders arrive automatically once the webhook above is live. To also pull the unfulfilled orders already sitting in your Shopify, add a read-only Admin API token once.

How to get the token (2 minutes, one time)
  1. Shopify Admin → Settings → Apps and sales channels → Develop apps
  2. Create an app → name it "NovaX" → Create
  3. Configuration → Admin API scopes → tick read_orders (and write_fulfillments if you want NovaX to mark orders fulfilled) → Save
  4. API credentials → Install app → copy the Admin API access token (starts with shpat_)

Stored server-side only. Never saved in this browser and never shown again.
